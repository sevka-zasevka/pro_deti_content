# ПРО дети

Этот репозиторий используется для **удалённого обновления контента** в мобильном приложении,
разработанном в рамках курсовой работы. Приложение автоматически загружает обновлённые версии
файлов при наличии доступа к интернету.

## Содержимое

| Файл            | Назначение |
|----------------|------------|
| `articles.json` | Материалы и статьи, посвящённые детской психологии и эмоциональному развитию |
| `games.json`    | Описания игр и активностей для детей |

## Как используется

Приложение проверяет наличие интернета и, при возможности, загружает актуальные версии JSON-файлов
с GitHub Pages. Загрузка позволяет обновлять контент **без переустановки приложения**.

## Обновление данных

1. Измените содержимое соответствующего JSON-файла  
2. Закоммитьте и отправьте изменения в ветку `main`  
3. GitHub Pages автоматически предоставит обновлённый контент приложению

## Заметки

- Репозиторий предназначен **только для хранения и обновления контента**
- Структура JSON должна оставаться совместимой с приложением
- Pull Request'ы на изменение контента не принимаются
